IBAC

Se a interface é negociada na hora por um modelo probabilístico, o que impede o desastre?

Faça a pergunta do slide em voz alta: é a que a plateia já está pensando. A foto dá a pista. Na imigração, o passaporte prova quem você é, mas o agente ainda pergunta qual é o propósito da viagem: a mesma pessoa, com o mesmo passaporte, entra como turista e pode ser barrada se disser que veio trabalhar sem visto. IBAC é isso: Intent-Based Access Control, controle de acesso pelo propósito, não pelo endpoint. (Foto: Unsplash, jXxdtXFEjcc, recortada e escurecida.)
