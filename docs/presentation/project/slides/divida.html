Sculley et al., “Hidden Technical Debt in Machine Learning Systems”, NIPS 2015

Todo mundo aqui conhece esse poste. Cada operadora que chega pendura mais um fio; ninguém tira os antigos, porque ninguém sabe mais qual fio é de quem. É a dívida de integração. A resposta da indústria é traduzir: conectores, descrições de ferramentas, schemas de function calling. Funciona, mas cada tradução vira um artefato permanente que alguém mantém. Com 8 sistemas já são 28 pares possíveis: o custo cresce com o número de pares que conversam, não com o valor entregue. Se alguém lembrar de ESB e modelo canônico, guarde para as perguntas.
