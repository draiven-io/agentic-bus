Na prática

Um agente em dois métodos

import asyncio

from agentic_bus import AgentCapability, BaseAgent

 

class WeatherAgent(BaseAgent):

    def capabilities(self):

        return [AgentCapability(

            capability_id="forecast",

            description="Previsão do tempo por cidade",

        )]

 

    async def execute_task(self, payload, context):

        return {"forecast": "ensolarado"}

 

agent = WeatherAgent(agent_id="weather-01")

asyncio.run(agent.run_forever())

Sem endpoint

Sem schema

Sem rota

pip install agentic-bus

Isto é tudo o que um agente precisa: dois métodos. Não há endpoint, schema nem rota. O agente se registra, o coordenador descobre a capacidade e a chama quando uma intenção pedir. E o agente não conhece ninguém: só declara o formato que precisa receber. Na hora de despachar, o coordenador mostra ao modelo só o formato do que já está na memória, nunca os dados, e compõe a entrada. No mundo sólido, esse mapeamento seria um adaptador mantido para sempre; aqui ele é calculado para a interação e some com ela. Na demo, um agente assim vai entrar ao vivo.
