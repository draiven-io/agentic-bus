Governança

Mesma chamada, propósitos diferentes

“Atender um cliente”

“Exportar a base inteira”

a mesma base

RBAC vê o papel. ABAC vê atributos. IBAC vê o propósito.

o mesmo agente

O mesmo agente, a mesma identidade, a mesma base de clientes. Lendo registros para atender um cliente, ele está trabalhando; com o propósito de exportar tudo, está exfiltrando. RBAC autoriza um papel chamando um endpoint, e o papel é estável. ABAC chega mais perto, mas o atributo que decide aqui é o porquê, e ele pertence à interação. IBAC avalia a interação, não a chamada.
