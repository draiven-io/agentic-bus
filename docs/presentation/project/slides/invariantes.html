A ideia

Quatro regras que não se negociam

Intenção primeiro

o ambiente de integração só se inicia se existir uma intenção a ser executada

Dissolução obrigatória

nada sobrevive à sessão

Acoplamento zero

nada vira premissa da próxima interação

Composição

vários agentes, um só acordo

Quatro regras que um sistema precisa cumprir para ser uma interface líquida; todas proíbem o que traria de volta o acoplamento estático. Intenção primeiro: um passo vale se aproxima do objetivo, não só se o formato está certo. Dissolução obrigatória e acoplamento zero: nada negociado sobrevive à sessão nem vira premissa da próxima. Composição: vários agentes podem resolver partes de uma intenção, e o acordo vale para o conjunto. As fotos servem de âncora: o alvo, a ampulheta, o plugue fora da tomada e as peças que se encaixam.
